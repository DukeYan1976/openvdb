# Marching Cubes 误差分析 — 设计文档

## 1. 问题定义

### 1.1 背景

Marching Cubes (MC) 算法是从体素化 SDF 提取等值面的标准方法。在 Yggdrasil-Midgard 中，MC 用于：
- **可视化**: MacroGrid → MC → GPU 渲染
- **Mesh 导出**: 将 SDF 体素转换为三角网格用于外部工具
- **表面分析**: 提取切削后的工件表面进行质量评估

### 1.2 误差来源分类

| 误差类型 | 来源 | 影响程度 |
|----------|------|----------|
| **位置误差** | 体素离散化 + 线性插值 | 主要 |
| **法线误差** | 中心差分梯度 + 插值 | 显著 |
| **拓扑误差** | 体素分辨率不足 | 关键 |
| **体积误差** | 表面偏移累积 | 长期 |

## 2. 数学模型

### 2.1 体素化 SDF 模型

设真实表面为 `S = {p | f(p) = 0}`，其中 `f` 是精确 SDF。

体素化后，在体素中心 `c_i` 采样得到 `f_i = f(c_i)`。MC 算法在每个体素边 `(c_i, c_j)` 上，若 `f_i · f_j < 0`（符号变化），则线性插值求交点：

```
p_edge = c_i + (0 - f_i) / (f_j - f_i) · (c_j - c_i)
```

### 2.2 位置误差上界

**定理 1 (线性插值误差)**:
设体素边长为 `V`，表面在该边方向上的曲率为 `κ`，则插值交点 `p_edge` 与真实交点 `p_true` 的误差：

```
|p_edge - p_true| ≤ V² · κ / 8 + O(V³)
```

**证明概要**:
- 在边方向上，`f` 是 `C²` 函数
- 线性插值误差由 Taylor 余项控制
- 二阶项系数与曲率 `κ = |∇²f · d|` 成正比
- 在边 `[0, V]` 上，最大误差出现在中点附近，为 `V²/8 · f''`

**推论**: 对于平面（`κ = 0`），MC 精确恢复；对于球面半径 `R`，`κ = 1/R`，误差上界 `V²/(8R)`。

### 2.3 法线误差

MC 使用中心差分估计梯度：

```
∇f ≈ (f(x+V) - f(x-V)) / (2V)
```

**定理 2 (梯度估计误差)**:

```
|∇f_approx - ∇f_true| ≤ V² · |∇³f| / 6 + O(V⁴)
```

法线方向误差：

```
Δθ ≈ |∇f_approx - ∇f_true| / |∇f_true|  (小角度近似)
```

对于球面 SDF `f(p) = |p| - R`，`∇f = p/|p|`，中心差分精确（径向对称），法线误差为零。

对于一般曲面，法线误差上界：

```
Δθ ≤ V² · κ_max / 6   (弧度)
```

### 2.4 阶梯效应 (Staircase Artifacts)

当表面与体素网格不平行时，MC 产生阶梯状表面。

**量化**: 设表面与网格夹角为 `α`，则阶梯高度：

```
h_stair = V · |cos α|
```

视觉上明显的阶梯出现在 `α ≈ 45°` 时，`h_stair ≈ V/√2`。

**缓解**: 自适应细分（如 Dual Contouring）或后处理平滑。

### 2.5 体积误差

MC 提取的表面包围体积与真实体积的误差：

```
ΔV/V ≈ O(V² · H)
```

其中 `H` 是平均曲率。对于凸体，体积误差随分辨率提高以 `O(V²)` 收敛。

## 3. 当前项目中的 MC 误差分析

### 3.1 MacroGrid 参数

| 参数 | 值 | 含义 |
|------|-----|------|
| `V_macro` | `K·t` (默认 K=30) | 体素尺寸 |
| `halfwidth` | 3 | 窄带半宽 |
| `t` | 用户公差 (0.001~0.1mm) | 目标精度 |

### 3.2 误差计算

**场景**: 精加工 `t = 0.01mm`, `V = 0.3mm`

| 误差类型 | 公式 | 数值 |
|----------|------|------|
| 位置误差 (球面 R=3mm) | `V²/(8R)` | `0.09/24 = 0.00375mm` |
| 位置误差 (平面) | `0` | `0` |
| 法线误差 | `V²·κ/6` | `< 0.005 rad ≈ 0.3°` |
| 阶梯高度 (45°) | `V/√2` | `0.21mm` |

**关键观察**:
- 位置误差 `0.00375mm < t = 0.01mm` ✅
- 但阶梯高度 `0.21mm >> t` ⚠️ — 视觉显著

### 3.3 与 MicroGrid 的关系

MacroGrid 的 MC 表面仅用于**可视化**，精度表面由 MicroGrid 的点云保证：
- MicroGrid 点位置精度: `t` (弦高约束)
- MicroGrid 法线精度: 解析梯度 (无离散误差)

因此，MC 误差不影响最终加工精度，但影响**视觉保真度**。

## 4. 误差控制策略

### 4.1 自适应 MC (Adaptive MC)

对高曲率区域局部细分：

```
if (local_curvature · V² > t) {
    subdivide_voxel();
}
```

### 4.2 平滑后处理

对 MC 表面应用 Laplacian 平滑（保持特征边）：

```
p_new = p + λ · Σ(q_i - p) / n
```

其中 `q_i` 是邻域顶点，`λ` 是平滑系数。

### 4.3 对偶轮廓 (Dual Contouring)

用 Hermite 数据（位置 + 法线）代替线性插值，误差降至 `O(V³)`：

```
p_optimal = argmin_p Σ(n_i · (p - p_i))²
```

## 5. 测试验证方案

### 5.1 解析曲面测试

| 曲面 | 解析 SDF | 测试目的 |
|------|----------|----------|
| 球面 | `\|p\| - R` | 验证位置误差上界 |
| 平面 | `n·p - d` | 验证精确恢复 |
| 圆柱 | `sqrt(x²+y²) - R` | 验证混合曲率 |

### 5.2 误差度量

```cpp
// Hausdorff 距离
double hausdorffDistance(const Mesh& mc, const Mesh& exact);

// 法线偏差
double normalDeviation(const Mesh& mc, const AnalyticSurface& exact);

// 体积误差
double volumeError(const Mesh& mc, double exactVolume);
```

## 6. 结论与建议

| 优先级 | 建议 | 影响 |
|--------|------|------|
| P1 | 当前 MC 仅用于可视化，误差可接受 | — |
| P2 | 如需高精度 Mesh 导出，使用 MicroGrid 点云 + 泊松重建 | 精度提升至 `t` |
| P3 | 如需 MC 可视化改进，实现 Adaptive MC 或 Dual Contouring | 视觉质量提升 |
| P4 | 添加运行时误差估计（基于局部曲率） | 用户反馈 |
