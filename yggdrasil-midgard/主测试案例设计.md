## 1. 核心验证逻辑

**关键命题**：只要相交线计算正确且逼近误差 ≤ t，切削后界面的所有特征（包括残高脊线）自然被保留。

因此集成测试的核心目标是验证：
1. 单次切削的相交线/界面精度 ≤ t
2. 多次切削后相交线之间的特征（残高）自然正确
3. 边界条件不崩溃

球头刀优先——有解析解可对比，残高有闭合公式。

---

## 2. 集成测试案例（球头刀）

### IT-1：单切精度验证

验证单次切削的界面精度。

| 项目 | 内容 |
|------|------|
| 毛坯 | 长方体 50×50×20 mm |
| 刀具 | 球头刀 R=5mm |
| 刀路 | X方向单段, (0,0,18)→(50,0,18), 切深2mm |
| 容差 | t=0.01mm |
| **验收** | MicroGrid 所有点到理论胶囊面距离 ≤ t |

### IT-2：双行残高验证

验证相邻切削的相交线特征保持。

| 项目 | 内容 |
|------|------|
| 毛坯 | 长方体 50×50×20 mm |
| 刀具 | 球头刀 R=5mm |
| 刀路 | 两行, 行距 s=3mm, 同深度 |
| 容差 | t=0.01mm |
| **验收** | Y=s/2 处残高 h 与理论值 `R-√(R²-(s/2)²)=0.231mm` 偏差 ≤ t |
| **重点关注** | 脊线处点集连续，无 gap |

### IT-3：空切 / 完全切除（边界条件）

| 子案例 | 输入 | 验收 |
|--------|------|------|
| 空切 | 刀路在毛坯上方 (Z=30mm) | MacroGrid/MicroGrid 状态不变 |
| 穿透 | 球头刀 R=15mm 从中心穿过 | 切削区 voxel 全部 inactive，剩余部分完整 |

### IT-4：多步累积稳定性

验证迭代不引入误差漂移。

| 项目 | 内容 |
|------|------|
| 毛坯 | 30×30×10 mm |
| 刀具 | 球头刀 R=3mm |
| 刀路 | 10行覆盖切削 (行距2mm, 交替方向) |
| 容差 | t=0.05mm |
| **验收** | 全部完成后全局 Hausdorff ≤ t；碎片率 < 30% |

## 3. 精度验证方法

**参考面**：球头刀扫掠体 = 胶囊体（球沿线段 Minkowski 和），解析 SDF 已知。

**Hausdorff 测量**：
- A = MicroGrid 实际点集
- B = 理论面密集采样（间距 t/10）
- kd-tree 加速最近点查询
- 报告 max(A→B) 和 max(B→A)

**残高直接测量**：在 Y=s/2 截面提取点的 Z 值，与解析值比较。
