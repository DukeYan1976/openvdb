## 摘要

**核心洞见**：为了兼顾对称性、物理切削特性（迎水面）以及几何解析的简洁性，将扫掠体切削面重构为 **6 分段参数面模型**。通过 $u$ 向（高度）和 $v$ 向（扫掠/宽度）的联合分段，实现了从工具底部极点到侧刃顶部的完整参数化覆盖。

**关键技术决策**：
1. **$u$ 向分层**：分为 Bottom 层（刀尖圆角/球头段）和 Top 层（圆柱侧刃段），解决 $G^1$ 连续转折点的数值敏感问题。
2. **$v$ 向三段式**：$S_{mid, Left} \to S_{cap, Front} \to S_{mid, Right}$，构成连续的切削前端（Waterline），直接对应物理上的“新切削区域”。
3. **对称性优先**：利用刀具与路径的对称性，统一 Left/Right 包络面的表达，简化计算逻辑。
4. **后向抛弃**：继续坚持抛弃后向端帽，确保 Phase 1/2 计算资源全部集中在有效切削区。

## 1. 6-Patch "迎水面" 模型架构

### 1.1 分段逻辑描述

参数域为规整的 $[0,1] \times [0,1]$，内部划分为 $2 \times 3$ 个区域：

| 区域 (u, v) | 物理含义 | 几何特性 |
| :--- | :--- | :--- |
| **P1: Bottom-Left-Mid** | 刀尖部左侧包络面 | 沿路径平移的圆弧/球面线 |
| **P2: Bottom-Front-Cap** | 刀尖部正前迎水面 | 终点位置的 180° 半球面/半圆角面 |
| **P3: Bottom-Right-Mid** | 刀尖部右侧包络面 | 沿路径平移的圆弧/球面线 |
| **P4: Top-Left-Mid** | 圆柱段左侧包络面 | 沿路径平移的垂直直线（平面） |
| **P5: Top-Front-Cap** | 圆柱段正前迎水面 | 终点位置的 180° 半圆柱面 |
| **P6: Top-Right-Mid** | 圆柱段右侧包络面 | 沿路径平移的垂直直线（平面） |

### 1.2 参数映射定义

#### $u$ 向分界 ($uSplit$)
对应刀具轮廓 $C(u)$ 中圆角/球面与圆柱段的切点。
- 球头刀：$uSplit = R / H$
- 牛鼻刀：$uSplit = (u_{flat} + u_{arc}) / 2$ (切点位置)

#### $v$ 向分界 ($v_1, v_2$)
基于弧长比例动态计算，以保证参数域采样的相对均匀：
设路径长度为 $L$，刀具半径为 $R$，总迎水面宽度 $W = 2L + \pi R$。
- $v_1 = L / W$
- $v_2 = (L + \pi R) / W$

## 2. 分段函数表达 (Piecewise Functions)

### 2.1 统一 1D 刀具轮廓 $C(u)$
三种刀型的 r(u), z(u) 定义如下。总切削高度 H = R + H_cut。

**球头刀**：
设 $uSplit = R / H$，则：
- $u \in [0, uSplit]$: $z(u) = -R \cos(\frac{\pi}{2} \frac{u}{uSplit})$, $r(u) = R \sin(\frac{\pi}{2} \frac{u}{uSplit})$
- $u \in [uSplit, 1]$: $z(u) = \frac{u-uSplit}{1-uSplit} H_{cut}$, $r(u) = R$

### 2.2 $v$ 向运动学表达 (3-axis Linear Move)

对于 $v \in [0, v_1]$ (Left Mid):
- $t = v / v_1$ (从 A 到 B)
- $\phi = \phi_{grazing, Left}$ (左侧擦掠角)
- $S(u, v) = P_{tool}(u, \phi) + A + t \cdot (B - A)$

对于 $v \in [v_1, v_2]$ (Front Cap):
- $w = (v - v_1) / (v_2 - v_1)$ (0 到 1)
- $\phi(w) = \phi_{start} + w \cdot \pi$ (跨越前向 180°)
- $S(u, v) = P_{tool}(u, \phi(w)) + B$

对于 $v \in [v_2, 1]$ (Right Mid):
- $t = 1.0 - (v - v_2) / (1.0 - v_2)$ (从 B 回到 A)
- $\phi = \phi_{grazing, Right}$ (右侧擦掠角)
- $S(u, v) = P_{tool}(u, \phi) + A + t \cdot (B - A)$

## 3. 设计优势与权衡

### 3.1 优势
1. **拓扑一致性**：将整个切削前端拉平为一个矩形参数域，QuadTree 细分时不会在 Mid 和 Cap 之间产生物理缝隙。
2. **精度可控**：圆柱段（P4-P6）是直纹面或圆柱面，采样步长可以放大；刀尖段（P1-P3）曲率高，自动触发深层细分。
3. **对称性利用**：P1/P3、P4/P6 在计算上高度相似，便于向量化实现。

### 3.2 性能预期
- **Phase 1 (BBox)**: 分段函数在子域内的 AABB 计算非常精确，减少了与 Voxel 匹配时的假阳性（False Positives）。
- **Phase 2 (Sampling)**: 迎水面模型过滤了 50% 以上的非切削表面，采样效率翻倍。

## 4. 潜在风险与质疑 (Expert Critique)

| 风险点 | 深度分析 | 应对措施 |
| :--- | :--- | :--- |
| **$C^1$ 不连续性** | 在 $v=v_1$ 和 $v=v_2$ 处，切线方向从进给方向突变为圆周方向。 | QuadTree 细分在缝隙处可能产生冗余节点。需在 Phase 1 分块时尽量让块边界对齐 $v_1, v_2$。 |
| **$u=0$ 极点奇异性** | 在刀尖南极点，$v$ 向的所有变化都收敛于一点。 | 在 $u < \epsilon$ 时，QuadTree 需提前终止，避免产生面积为 0 的退化三角形。 |
| **$v$ 向参数扭曲** | 当路径 $L$ 极短而半径 $R$ 极大时，Mid 段在参数空间占比极小，可能导致采样不足。 | 采用动态 $v_1, v_2$ 比例。极端情况下（$L=0$），$v_1, v_2 \to 0.5$，$v$ 域退化为纯 Cap。 |
| **法线突变** | 虽然位置连续，但非平滑连接处的法线插值可能导致 Phase 3 的重建出现微小波纹。 | 强制采样点必须使用解析法线而非网格插值法线。 |
