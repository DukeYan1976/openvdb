## 1. 6-Patch "迎水面" 模型架构 (弧长优化版)

### 1.1 参数域权重分配

为了使参数空间 $[0,1]$ 内的采样点在 3D 空间中分布尽可能均匀（接近等弧长采样），$v$ 向的分界点 $v_1, v_2$ 应严格遵循各段物理宽度的比例：

- **Left-Mid 宽度**: $L$ (路径长度)
- **Front-Cap 宽度**: $\pi \cdot R$ (前向 180° 圆弧/半圆柱弧长)
- **Right-Mid 宽度**: $L$ (路径长度)
- **总物理宽度**: $W_{total} = 2L + \pi R$

**准弧长分界点定义**：
$$v_1 = \frac{L}{2L + \pi R}$$
$$v_2 = \frac{L + \pi R}{2L + \pi R}$$

这种映射确保了：
1. 当 $L \gg R$ 时，Mid 段占据主导，采样集中在侧面。
2. 当 $R \gg L$ 时，Cap 段占据主导，采样集中在前部。
3. 当 $L=0$ 时，$v_1=0, v_2=1$，参数面自动且平滑地退化为纯 Cap 模型（全圆 $2\pi R$）。

## 2. 局部误差模型与连续性分析

### 2.1 $C^1$ 不连续的容忍性
虽然在 $v_1, v_2$ 处存在 $C^1$ 不连续（切向量从进给方向 $\mathbf{d}$ 瞬变为圆周切向 $\mathbf{\tau}$），但目前的 Phase 2 细分算法基于 **局部弦高误差 (Local Chordal Error)**：

$$\delta = \| S(u_{mid}, v_{mid}) - \frac{1}{2}(S(u_0, v_0) + S(u_1, v_1)) \|$$

**分析结论**：
- **无精度损失**：采样点始终精确落在解析曲面上。
- **鲁棒性**：误差计算仅依赖点的位置，不依赖参数域的一阶或二阶导数。
- **细分行为**：在接缝处，由于跨越了非线性转折，双线性插值的预测值会偏离真实面，导致 QuadTree 在接缝局部多细分 1-2 层。这被认为是**可接受的微小开销**，换取了全局参数化逻辑的极度简化。

## 3. 分段函数表达 (Piecewise Functions)

### 3.1 $v$ 向运动学表达 (3-axis Linear Move)

对于 $v \in [0, v_1]$ (Left Mid):
- $t = v / v_1$ (归一化路径进度 0 $\to$ 1)
- $\phi = \phi_{grazing, Left}$
- $S(u, v) = P_{tool}(u, \phi) + A + t \cdot (B - A)$

对于 $v \in [v_1, v_2]$ (Front Cap):
- $w = (v - v_1) / (v_2 - v_1)$ (归一化角度进度 0 $\to$ 1)
- $\phi(w) = \phi_{start} + w \cdot \pi$
- $S(u, v) = P_{tool}(u, \phi(w)) + B$

对于 $v \in [v_2, 1]$ (Right Mid):
- $t = 1.0 - (v - v_2) / (1.0 - v_2)$ (归一化路径进度 1 $\to$ 0)
- $\phi = \phi_{grazing, Right}$
- $S(u, v) = P_{tool}(u, \phi) + A + t \cdot (B - A)$

## 4. 潜在风险与质疑 (Expert Critique - v0.d)

| 风险点 | 深度分析 | 应对措施 |
| :--- | :--- | :--- |
| **Mid 段方向反转** | P3 (Right Mid) 采用了 $t: 1 \to 0$ 的映射。 | 目的是为了保证 $S(u, v=0)$ 和 $S(u, v=1)$ 都位于起点 A 的两侧，形成闭合的对称逻辑。 |
| **小路径尺寸效应** | 当 $L < \epsilon$ 时，$v_1$ 极小。 | 需在代码中加入 `if (v1 > 1e-9)` 的分支保护，避免归一化除零。 |
| **$u$ 向弧长匹配** | 目前 $u$ 向尚未采用弧长比例。 | 球头刀 $u$ 建议映射为纬度角 $\alpha$，牛鼻刀映射为轮廓累计弧长。 |

## 5. 实现建议

在 `ToolSweepSurface` 构造函数中预计算：
```cpp
double arcCap = M_PI * mTool.R;
double arcTotal = 2.0 * mLength + arcCap;
mV1 = mLength / arcTotal;
mV2 = (mLength + arcCap) / arcTotal;
```
并在 `eval` 函数中使用 `std::lower_bound` 或简单的 `if-else` 进行分段检索。
