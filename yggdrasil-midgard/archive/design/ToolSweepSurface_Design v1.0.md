## 1. 6-Patch "迎水面" 模型架构 (最终版)

### 1.1 全刀型统一分层 (u-direction)
为了处理牛鼻刀和平底刀的复杂轮廓，参数 $u \in [0, 1]$ 被划分为三个物理区间：

1.  **区间 1: Bottom Flat (底平段)**
    *   $u \in [0, uSplit1]$
    *   物理形态：圆盘或环形平底。
    *   法向：恒定 $(0, 0, -1)$。
2.  **区间 2: Corner Arc (圆角段)**
    *   $u \in [uSplit1, uSplit2]$
    *   物理形态：1/4 圆弧（纬度角 $\alpha \in [0, \pi/2]$）。
    *   **数值圆角补偿 (Numerical Fillet)**：对于平底刀（Flat-End），自动插入一个 $r=0.01$mm 的极小圆角。这消除了 QuadTree 在 90° 尖角处因法线突变导致的无穷递归。
3.  **区间 3: Cylindrical (圆柱段)**
    *   $u \in [uSplit2, 1]$
    *   物理形态：圆柱侧刃。
    *   法向：水平 $(n_x, n_y, 0)$。

### 1.2 准弧长映射权重
分段点由各段物理弧长比例决定：
$$uSplit1 = H_{flat} / (H_{flat} + H_{arc} + H_{cyl})$$
$$uSplit2 = (H_{flat} + H_{arc}) / (H_{flat} + H_{arc} + H_{cyl})$$

## 2. 切削前端 (v-direction) 闭合映射

$v \in [0, 1]$ 构成连续的迎水面：
- **Left-Mid**: $v \in [0, v_1]$，对应路径 $t: 0 \to 1$。
- **Front-Cap**: $v \in [v_1, v_2]$，对应前向半圆 $\phi: \phi_L \to \phi_R$。
- **Right-Mid**: $v \in [v_2, 1]$，对应路径 $t: 1 \to 0$。

这种映射使得 $v=0$ 和 $v=1$ 都在起点 A 的两侧，物理上形成一个完美的切削半环，便于 QuadTree 在扫掠起始位置的闭合处理。

## 3. 数值稳定性与精度原则

### 3.1 平底刀尖角处理
平底刀的数值圆角 $r_{num}$ 应满足 $\delta_{chordal} / 2 < r_{num} < V_{voxel}$。当前实现取 $0.01$mm。
*   **SDF 一致性**：`ToolSweptSDF` 已同步采用 `roundedCylinderSDF` 模型，确保 eval(p) 在圆角处依然精确。

### 3.2 法线计算
禁止使用参数空间数值差分。所有 Patch 必须使用基于极坐标变换的**解析法线**，以确保 Phase 3 Reconstruction 阶段不产生伪褶皱。
