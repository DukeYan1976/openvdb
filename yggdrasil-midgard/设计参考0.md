# 工业级多轴切削仿真算法 V4.0 设计方案

## 1\. 核心架构范式

本算法采用 **Host-Device 解耦模式**，结合双轨制混合表达与读前写保护时序，引入极简正向预分块（保守裕量外扩）技术，通过单趟四叉树 3D 拒止求值实现高效计算。

  * **全局控制参数**：单一用户容差 $\epsilon$ (如 0.001 mm)。

-----

## 2\. 算法宏观并行流水线 (Macro Parallel Pipeline)

本算法分为 5 个 Phase，其中 Phase 0-1 运行于 CPU 主线程，Phase 2-4 运行于 TBB 并行线程池或 GPU CUDA 网格。

  * **Phase 0 (Host): 宏观碰撞粗筛与内存大块去活**
    利用 `FloatGrid` 瞬间释放被完全切除的内存区域，锁定活跃体素边界。
  * **Phase 1 (Host): 基于正向物理覆盖与裕量外扩的极简预分块**
    将理论参数面划分为 2D 参数块，计算其 3D AABB 并与体素（Voxel）匹配。通过外扩安全步长（Margin）形成保守任务包，实现 $O(1)$ 或 $O(\log N)$ 的任务下发。
  * **Phase 2 (TBB 并发): 单趟自适应四叉树极速求值与核内裁边**
    利用只读的旧 IPW 代理在参数域细分，并通过 3D AABB 拒止切除 Phase 1 引入的冗余裕量，生成特征点云。
  * **Phase 3 (TBB 并发): 非对称布尔剔除与边界重投影**
    并行遍历旧点云，执行硬删除或通过 SDF 梯度重投影消除离散锯齿。
  * **Phase 4 (TBB 并发): 无锁相对坐标无损注射**
    将点坐标转换为相对于体素中心的偏移量 $[-0.5, 0.5]^3$，并无锁注入对应体素内存。

-----

## 3\. 算法微观细节与数学模型

### 3.1 极简预分块 (Forward AABB Covering & Margin Expansion)

本步骤通过将 2D 参数子块映射至 3D 物理包围盒，避免了逆向求导计算。

  * **判定逻辑**：若 3D 包围盒与活跃 Voxel AABB 相交，则将参数定义域外扩安全裕量 $\Delta_{safe}$。
  * **优势**：彻底免疫数学奇异点，天然适配参数域的极端拉伸。

### 3.2 边界重投影 (Asymmetric Reprojection)

对于过渡区的点，采用 SDF 梯度重投影技术将点拉回至解析等值面，公式如下：

$$\mathbf{p}_{new} = \mathbf{p}_{old} - SDF_{csv}(\mathbf{p}_{old}) \cdot \nabla SDF_{csv}(\mathbf{p}_{old})$$

其中：

  * $\mathbf{p}_{old}$：原始点坐标
  * $SDF_{csv}(\mathbf{p}_{old})$：刀具 SDF 场在该点的标量值
  * $\nabla SDF_{csv}(\mathbf{p}_{old})$：刀具 SDF 场在该点的梯度向量

## 4\. C++ 并行实现架构 (Pseudocode)

### 4.1 任务打包 (Phase 1)

``` cpp
struct VoxelTaskPayload {
    NanoVDB_LeafNode* voxel_ptr; 
    BoundingBox voxel_aabb;      // 目标体素物理 3D 包围盒
    Range u_conservative;        // 携带安全裕量的保守 U 域
    Range t_conservative;        // 携带安全裕量的保守 T 域
};

std::vector<VoxelTaskPayload> PrepareVoxelTasks_V4(LeafManager active_leaves, Manifold S_uv) {
    std::vector<VoxelTaskPayload> tasks;
    std::vector<ParametricBlock> param_blocks = DivideManifoldIntoBlocks(S_uv);
    
    tbb::parallel_for(active_leaves, [&](LeafNode& voxel) {
        BoundingBox v_aabb = voxel.get_AABB();
        Range u_local, t_local;
        bool has_intersection = false;
        
        for (const auto& block : param_blocks) {
            BoundingBox block_aabb = Compute3DBBox(S_uv, block.u_range, block.t_range);
            if (v_aabb.intersects(block_aabb)) {
                u_local.expand(block.u_range);
                t_local.expand(block.t_range);
                has_intersection = true;
            }
        }
        
        if (has_intersection) {
            u_local.add_margin(SAFE_MARGIN_U);
            t_local.add_margin(SAFE_MARGIN_T);
            tasks.push_back({&voxel, v_aabb, u_local, t_local});
        }
    });
    return tasks;
}

```

## 5\. 性能优化建议：内存碎片规整 (Batched Compaction)

为了解决动态加工产生的显存碎片问题，建议在 Phase 3 后引入以下机制：

1.  **显存碎片规整 (Memory Compaction)**：使用 GPU 并行前缀和（Prefix-Sum）算法，定期将标记为“死亡”的 Point 数据从连续数组中剔除。
2.  **缓冲区回收**：腾出的叶节点指针应回收到全局缓冲池中，而非仅依赖软删除掩码。
3.  **周期性 Cleanup 算子**：系统应设定固定阈值（例如每 1000 次求交操作后），强制执行 Cleanup 算子，重组树结构以保障 L1/L2 缓存命中率。
