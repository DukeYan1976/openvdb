## 1. 核心架构：解耦的双轨系统 (Dual-Grid Architecture)

针对现代高端制造对 1μm 精度与超大规模（2000mm+）仿真的双重需求，本引擎采用 OpenVDB 底层框架，构建解耦的“双轨”空间拓扑：

### 1.1 共享变换枢纽 (The Shared Transform Hub)
*   **设计原则**：宏观轨与微观轨必须共享完全一致的 `openvdb::math::Transform` 结构。
*   **物理意义**：逻辑坐标 $(i, j, k)$ 在两轨间具有隐式硬对齐，消除显式索引开销。

### 1.2 轨道 A：宏观索引轨 (Macro Track)
*   **组件**：`openvdb::DoubleGrid` (稀疏 VDB 树)。
*   **职责**：
    *   **空间索引**：管理全局毛坯的动态拓扑结构。
    *   **干涉判定**：存储低分辨率标量 SDF，用于秒级全局碰撞检测。
    *   **状态维护**：维护 FULL/EMPTY/BOUNDARY 三态。

### 1.3 轨道 B：微观几何轨 (Micro Track)
*   **组件**：`openvdb::points::PointDataGrid` (SoA 布局)。
*   **职责**：
    *   **高精几何**：存储 1μm 级别的面元（Surfel）点云。
    *   **材料剥离**：利用位掩码属性 `ActiveMask` 执行零拷贝布尔运算。
    *   **计算加速**：通过 SoA 布局适配 AVX-512 指令集，实现高吞吐剔除。

## 2. 确定性分辨率决策算法 (CSP Solver)

根据零件特征与工艺参数，动态计算最优宏观体素尺寸 $D_v$：

### 2.1 约束满足问题 (CSP) 定义
*   **输入**：精度公差 $t$, 最小刀半径 $R_{min}$, 最小特征 $F_{min}$, 包围盒跨度 $L_{max}$。
*   **微观基准**：$d_v = 0.5 \times t$。
*   **物理上界**：$D_{upper} = \min(0.5 \times R_{min}, F_{min})$。
*   **对齐均衡解**：选取 $N$ 使得 $N = 2^n$ 且最接近 $\lfloor D_{upper} / d_v \rfloor$。
*   **最优尺寸**：$D_v = N \times d_v$。

### 2.2 架构降级红线
*   **单轨降级**：若 $N < 32$，停用双轨，回退至单轨 Micro Grid 模式。
*   **精度墙处理**：若 $L_{max} / d_v > 1.67 \times 10^7$，触发 **Atlas-Region** 局部坐标系切片机制。

## 3. 超大型零件管理 (Atlas-Region Manager)

为解决大型零件仿真的浮点坍塌与内存压力：

### 3.1 三层空间分级
1.  **Atlas (星图)**：全局 Spatial Hash 映射。
2.  **Region (局部星系)**：拥有独立 **Floating Origin**（通常为 1000mm 级）。
3.  **Grid (双轨核心)**：Region 内部执行高精度仿真。

### 3.2 动态 LOD 策略
*   **切削区**：激活全量双轨（Macro + Micro）。
*   **干涉区**：仅保留 Macro Grid 的 SDF 标量场，支撑极速干涉检查。
*   **静态区**：内存置换 (Swap) 至 NVMe。

## 4. 关键算法逻辑 (Key Pipelines)

### 4.1 3 轴/5 轴切削流水线
*   **GSV 聚合**：对 G 代码行执行预解析，生成广义扫掠体包围盒。
*   **无分支 SDF**：计算面元至刀具包络面的距离场，全过程无条件分支惩罚。
*   **逆向轨迹 (Inverted Trajectory)**：5 轴扩展时采用面元运动逆向求交。

### 4.2 异步 RCU 紧凑化
*   利用后台线程执行 `compactAttributes`，通过 `std::atomic_exchange` 挂载紧凑节点，彻底避免内存碎片导致的爆炸。
